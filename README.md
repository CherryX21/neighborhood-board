# Дошка оголошень

Програмування веб-застосувань, практичні роботи.

Проєкт: neighborhood-board (варіант 18).

Поточний етап: практична робота №14 — власний сервер Node.js (Express) у теці server/: роздає файли клієнта та віддає оголошення через GET/POST /api/posts, а клієнт отримує дані з нього замість публічного API (попередні етапи: №13 — SPA з hash-маршрутизацією, №12 — CSS-анімація нового оголошення, №11 — IndexedDB, №10 — Vue 3, №9 — клієнт для API).

## Запуск

```bash
cd server
npm install
npm start
```

Після запуску сторінка доступна за адресою http://localhost:3000. Сторінку потрібно відкривати саме з цього сервера: запит до API відносний (`/api/posts`), тому Live Server без Node-сервера оголошень не отримає.

Інший порт: `PORT=3001 npm start`. Режим із автоперезапуском: `npm run dev`.

## API

| Метод | Адреса | Відповідь |
| :--- | :--- | :--- |
| GET | /api/posts | 200, масив оголошень |
| GET | /api/posts/:id | 200, одне оголошення, або 404 |
| POST | /api/posts | 201 і створене оголошення, або 400/413 |
