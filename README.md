# Дошка оголошень

Програмування веб-застосувань, практичні роботи.

Проєкт: neighborhood-board (варіант 18).

Поточний етап: практична робота №13 — SPA з hash-маршрутизацією (js/router.js): #/ — стрічка, #/category/:category — фільтр, #/posts/:id — оголошення, #/new — форма, невідома адреса — сторінка «Не знайдено» (попередні етапи: №12 — CSS-анімація нового оголошення, №11 — збереження оголошень користувача в IndexedDB із міграцією з localStorage, №10 — Vue 3 і компонент AdCard, №9 — клієнт для публічного API).
