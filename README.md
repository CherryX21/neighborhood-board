# Дошка оголошень

Програмування веб-застосувань, практичні роботи.

Проєкт: neighborhood-board (варіант 18).

Поточний етап: практична робота №12 — CSS-анімація появи нового оголошення (slide-down + fade-in) і позначка «Нове», що плавно згасає (попередні етапи: №11 — збереження оголошень користувача в IndexedDB із міграцією з localStorage, №10 — Vue 3 і компонент AdCard, №9 — клієнт для публічного API).
