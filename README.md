# Дошка оголошень

Програмування веб-застосувань, практичні роботи.

Проєкт: neighborhood-board (варіант 18).

Поточний етап: практична робота №11 — збереження оголошень користувача в IndexedDB (js/storage.js) з одноразовою міграцією з localStorage та резервним режимом localStorage (попередні етапи: №10 — Vue 3 і компонент AdCard, №9 — клієнт для публічного API).
